# Content map

This repository supports one short recorded walkthrough and a set of deeper
manuals.

## Main route

The recording follows one synthetic data-science operations task:

1. frame the adoption problem;
2. inspect the project;
3. define scope and acceptance checks;
4. plan the change with GitHub Copilot CLI;
5. apply project instructions and a skill;
6. use a read-only MCP source;
7. implement a small change;
8. run deterministic checks;
9. inspect the full diff;
10. review the result;
11. explain model and token choices.

The recording is the overview. The runbooks provide the detail.

## Planned material

| Area | Purpose |
|---|---|
| `synthetic-project/` | Runnable data-science operations example |
| `runbooks/` | Step-by-step instructions |
| `slides/` | Marp source and generated slide material |
| `diagrams/` | D2 source and rendered diagrams |
| `outreach/` | Public summaries for related writing |

These areas are added in later, reviewed changes.

## Audience

The primary audience is data scientists who use AI tools and want a practical
introduction to agentic development.

The material starts with a small task. It introduces one control at a time.
It does not assume that the reader will run an autonomous agent.

## Public boundary

The video and local recording files are not part of this repository. The
repository contains only the public script, examples, and manuals needed to
repeat the walkthrough.

All examples must use synthetic data. Do not add private work context.
