# Preflight fixture conventions

This is a disposable toy project for rehearsing governed Copilot work.

- Read `README.md`, `.github/copilot-instructions.md`, and `TASKS.md` first.
- `TASKS.md` is the only task register for this fixture.
- Create `TASK.md` as the active contract before task work.
- Keep the task bounded to `src/sample.txt` and the approved checks.
- Use synthetic, public-safe content only.
- Record a receipt before any history-changing request.
- Write `HANDOVER.md` only at the approved stopping point.
- Do not commit or push; do not publish, install packages, or register MCP.
