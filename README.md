# Agentic development playbook

Public, synthetic material for practical agentic development in enterprise and
data-science operations.

The repository includes a GitHub Copilot CLI walkthrough. It covers project
context, skills, hooks, MCP, review, governance, and model efficiency.

This material was prepared for a Department for Education demonstration. It is
independent. It is not official DfE guidance.

## Start here

1. Read [`CONTENT-MAP.md`](CONTENT-MAP.md).
2. Read [`runbooks/README.md`](runbooks/README.md).
3. Use the planned recording sequence as the main route.
4. Use the deep-dive runbooks for detail.

The examples use synthetic data. Do not add work data, personal data, secrets,
private endpoints, or internal procedures.

## What this playbook teaches

- how to prepare a project for an agent;
- how to give an agent useful project context;
- how to turn repeated work into a skill;
- how to add controlled tools through MCP;
- how to use hooks for checks and safety;
- how to plan, implement, test, review, and document a change;
- how to choose a suitable model for each task;
- how to measure useful work rather than logins or prompt counts.

The recorded walkthrough uses GitHub Copilot CLI. The method is broader than
one harness. Harness-specific details belong in the relevant runbook.
